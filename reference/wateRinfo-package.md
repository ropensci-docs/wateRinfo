# wateRinfo: Download Time Series Data from Waterinfo.be

wateRinfo facilitates access to waterinfo.be
(\<https://www.waterinfo.be\>), a website managed by the Flanders
Environment Agency (VMM) and Flanders Hydraulics Research. The website
provides access to real-time water and weather related environmental
variables for Flanders (Belgium), such as rainfall, air pressure,
discharge, and water level. The package provides functions to search for
stations and variables, and download time series.
